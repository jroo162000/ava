WHEN: User asks to screenshot and visually inspect an open interface element
STEPS:
1. Ask the user to confirm the specific area/window they want captured.
2. Use screen_ops with operation:'screenshot' to capture the image.
3. Describe observed layout, alignment, colors, text readability, and any anomalies in the screenshot.
4. Provide a brief opinion on overall appearance and suggest improvements if any issues are found.
