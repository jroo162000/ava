WHEN: when you need to find and display the latest .glb file in an ava models folder
STEPS:
1. Run fs_find with pattern '*.glb' in the directory C:\Users\Dell\Downloads\ava_models to locate all models.
2. Sort the results by file creation/modification time to identify the newest .glb file.
3. Open the newest .glb file using a compatible viewer or hologram application.
4. Place the loaded model onto the display panel (e.g., by drag-and-drop, import, or using the app's alignment tools).
