WHEN: User says 'baby', 'display open', or mentions holographic tabs
STEPS:
1. Acknowledge that user has a screen open and their tabs are visible to you
2. Use the displayed tabs directly instead of asking which ones to use
3. Treat any mention of 'baby' or 'holographic tabs' as a cue to check the open display first
