WHEN: need to create a text file with a haiku or short poem in the Downloads folder
STEPS:
1. Open Notepad if not already open
2. Type a haiku (e.g., 'Old pond / A frog jumps / Splash of water' or a custom one)
3. Press Ctrl+S to open Save As dialog
4. Navigate to C:\Users\Dell\Downloads
5. Set file name to wf14_abort.txt
6. Click Save
7. Optionally read back the file using notepad or type command
